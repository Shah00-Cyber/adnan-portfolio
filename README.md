# Personal Portfolio Website 🚀

Welcome to the repository of my professional personal portfolio website. This project showcases my skills, experience, projects, and educational background in a clean, modern, and interactive interface.

## 🌐 Live Demo
You can view the live website here: [shahadnan-portfolio.vercel.app](https://shahadnan-portfolio.vercel.app)

## ✨ Features
- **Responsive Design:** Optimized for all screen sizes (Desktops, Tablets, and Mobile phones).
- **Interactive UI:** Smooth transitions and modern layout design.
- **Project Showcase:** Highlights technical projects with descriptions and preview details.
- **Contact & Social Links:** Direct access to GitHub, LinkedIn, and professional platforms.

## 🛠️ Tech Stack Used
- **HTML5:** For structured layout semantic components.
- **CSS3:** For custom modern styling, responsive media queries, and animations.
- **JavaScript:** For dynamic interactivity and functional components.
